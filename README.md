# Install Packets Script 2.0

Интерактивный установщик для OpenWrt 24.10.x (`opkg`) и 25.12.x (`apk`). Версия: **2.0.5**. BusyBox ash / POSIX sh.

Версия 2.0.5 удаляет пункты Zapret2 Routerich и Tailscale. Оставшиеся пункты пронумерованы подряд.

## Запуск — команда сохранена

```sh
wget -O /tmp/install_packets_script.sh \
  https://raw.githubusercontent.com/TMN88/install_packets_script/main/openwrt-toolkit.sh \
  && sh /tmp/install_packets_script.sh
```

Команда всегда скачивает последнюю опубликованную версию из `main`.

## Установка и обновление актуальных версий

При выборе любого приложения его штатный установщик или обновлятор запускается и для уже установленной версии. Пакеты из feed обновляются по одному; полный апгрейд системы не выполняется. Для приложений из GitHub загружается текущий опубликованный установщик. Внешний обновлятор вправе завершиться без замены файлов, если проверил, что установлен тот же актуальный payload. Текущие опубликованные версии: VPN Failover **0.2.1**, Site Checker **2.0.0-local.6**, YouTube Watchdog **1.4.1**.

VPN Failover сохраняет конфигурацию, состояние службы и автозапуска при обновлении. На первой установке он остаётся остановленным и отключённым до проверки. Site Checker 2.x сохраняет настройки; при миграции с 1.x создаётся резервная копия. Для Watchdog используется отдельный `update.sh` с закреплённым payload и SHA256SUMS; настройки, интервал и состояние running/enabled сохраняются. Если его payload уже совпадает с опубликованным, обновлятор оставляет файлы и службу без изменений.

Номера можно разделять пробелами и запятыми; повторения игнорируются. Действия выполняются в порядке выбора. Ошибка одного компонента не останавливает остальные. План выводится до установки без общего запроса подтверждения.

**A** выбирает только AmneziaWG, Site Checker 2.0, USB Modules и Watchdog. Podkop/Forkop, Zapret Manager, VPN Failover, темы, SFTP и ttyd остаются ручным выбором. Несовместимые пункты пропускаются. Классический Zapret2 автоматически не устанавливается.

Русская локализация LuCI автоматически устанавливается или обновляется после выбора компонентов. При Q или завершении ввода установки нет. Границы НАЧАЛО / КОНЕЦ и итоговая таблица показываются по-русски; `NO_COLOR=1` отключает ANSI.

## Совместимость и сохранение настроек

Проверяются точная ветка OpenWrt, соответствие менеджера пакетов и наличие архитектуры. Для внешних компонентов конкретные сборки, архитектуры и зависимости проверяет их штатный установщик / менеджер пакетов. Наличие пункта меню не означает поддержку любого процессора; отказ внешней установки учитывается как ошибка. Поддержка оборудования не подтверждена mock-тестами.

Podkop и Forkop не ставятся поверх друг друга, учитываются существующие конфигурации. Zapret Manager не ставится поверх Zapret2. При выборе установленного приложения обновляющий обработчик выполняется снова после защитных проверок конфликта.

Перед миграцией Site Checker сохраняются старые конфигурации, затем выполняется штатный `Site_Checker_2/main/install.sh`. Остатки 1.x не считаются версией 2.0. Существующие настройки 2.x сохраняет штатный установщик.

Watchdog устанавливается и без Zapret2, с предупреждением. Его собственная диагностика и штатная политика восстановления сохраняются: интервал по умолчанию 180 секунд, подтверждение отказа, ограничение попыток. Параметры уже существующего Watchdog сохраняются даже если внешний установщик пытается мигрировать режим. Полная, но отключённая установка отмечается «ТРЕБУЕТ НАСТРОЙКИ» без включения службы.

SFTP и ttyd устанавливаются или обновляются **только по выбору**. Для уже установленных пакетов обновляется только выбранный пакет, общий список системы не обновляется. Порт SSH, ключи, правила входа и firewall не меняются; Dropbear не отключается, OpenSSH daemon не устанавливается. Для Dropbear при необходимости создаётся отсутствующая ссылка на штатный subsystem. Для OpenSSH проверяется эффективный Subsystem через `sshd -T`; неподтверждённая интеграция требует ручной настройки. Установка пакета не является проверкой подключения из Termius/WinSCP.

Темы запускают оригинальное меню. Перед запуском сохраняется конфигурация LuCI, при ошибке она восстанавливается. Другие темы не удаляются, перезагрузки нет. Выбранная активная тема указывается в отчёте. Отмена не считается успешной активацией.

Приватные резервные копии приложений хранятся в `/etc/install-packets-backups/run.*/` (каталоги 700, umask 077). Они не удаляются автоматически. Перед сетевыми установщиками сохраняются network/firewall/dhcp и конфигурации обходчиков. Копии могут содержать секреты — храните их как конфигурацию роутера. Восстановление сетевых настроек выполняется вручную после анализа причины ошибки, чтобы не прервать доступ произвольным откатом.

Внешние shell-файлы загружаются только с заданных HTTPS-источников в отдельный временный каталог, проверяются на непустое содержимое, shebang и `sh -n`. Штатные проверки SHA256 Site Checker, Watchdog и установщика тем сохраняются. Внешние URL указывают на текущие штатные установщики: их последующие изменения не являются протестированной частью этой версии. Временный каталог текущего запуска удаляется; чужие/старые каталоги не очищаются.

Скрипт не вызывает `reboot`. После подтверждённой установки AmneziaWG в текущем запуске напоминает о ручной перезагрузке при необходимости.

## Результаты

Статусы: УСПЕШНО, УСТАНОВЛЕН РАНЕЕ, ОШИБКА, НЕ ПОДДЕРЖИВАЕТСЯ, ТРЕБУЕТ НАСТРОЙКИ, ПРОПУЩЕНО. Нулевого кода внешнего установщика недостаточно: проверяется конечное состояние. Ошибки дают ненулевой итоговый код; ручная настройка и пропуски отражаются отдельно.

## Проверки

```sh
sh -n openwrt-toolkit.sh
busybox ash -n openwrt-toolkit.sh
shellcheck --severity=style --shell=sh openwrt-toolkit.sh
python3 -m unittest discover -s tests -v
```

CI повторяет синтаксические проверки, ShellCheck и mock-сценарии под dash и BusyBox ash. Тесты не скачивают и не выполняют внешние установщики: их заменяют управляемые имитации. Проверяются opkg/apk, конфликты, повторный запуск, частичные ошибки, миграция, SFTP, темы, отсутствие GitHub и ложный код успеха.

**Для локальной 2.0.5 тесты и аппаратная проверка не запускались.** Ранее описанные mock/CI проверки относятся к прежнему состоянию; они не подтверждают обновление выбранных приложений, SFTP-сессию, удалённый SSH, восстановление YouTube или работу модулей ядра на конкретном роутере.

## Исправление отчёта Zapret Manager (2.0.2)

Панель устанавливается файлами, независимо от пакета и службы движка Zapret. Поэтому проверяются её backend, RPC-плагин, меню и ACL LuCI, common.js и dashboard.js. Для полной готовности дополнительно проверяются регистрация RPC, файлы отдельного Web UI, uhttpd-mod-ubus, секция uhttpd.zmweb и работа uhttpd.

При каждом выборе повторно запускается текущий установщик панели. Готовая панель после этого даёт «УСПЕШНО». Если файлы панели на месте, но RPC/Web UI не готовы, выводится «ТРЕБУЕТ НАСТРОЙКИ». Ненулевой код дочернего установщика или отсутствие обязательных файлов после обновления остаются «ОШИБКОЙ». Само наличие службы Zapret не считается установленной панелью. Проверка браузерного подключения с клиента не выполняется. Общая команда wget не меняется.
