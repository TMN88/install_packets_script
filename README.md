# Install Packets Script for OpenWrt

Интерактивный shell-скрипт для выборочной установки сетевых компонентов на OpenWrt. Запускать по SSH от `root`.

## Быстрый запуск

```sh
wget -O /tmp/install_packets_script.sh https://raw.githubusercontent.com/TMN88/install_packets_script/main/openwrt-toolkit.sh && sh /tmp/install_packets_script.sh
```

Скрипт определяет версию OpenWrt, менеджер пакетов (`opkg` или `apk`), target и архитектуру, показывает меню и запрашивает подтверждение перед установкой.

## Доступные компоненты

1. **Podkop** — [itdoginfo/podkop](https://github.com/itdoginfo/podkop). Если в установщике доступен пакет русской локализации, скрипт автоматически выбирает русский язык и не задаёт вопрос.
2. **Forkop (Podkop Plus)** — [ushan0v/forkop](https://github.com/ushan0v/forkop), альтернативный форк Podkop.
3. **AmneziaWG** — [2Grey/awg-openwrt](https://github.com/2Grey/awg-openwrt); используется `amneziawg-feed-install.sh`, который настраивает подписанный feed для текущей версии OpenWrt/target и устанавливает пакеты AmneziaWG.
4. **Zapret Manager** — [StressOzz/Zapret-Manager](https://github.com/StressOzz/Zapret-Manager).
5. **Zapret2 от Routerich** — пакетная сборка только для OpenWrt 24.10/`opkg` или 25.12/`apk`, target `mediatek/filogic` и архитектуры `aarch64_cortex-a53`. Если версия OpenWrt, target/архитектура или пакеты Routerich не подходят/недоступны, скрипт выводит ошибку и пропускает установку Zapret2. Автоматического перехода на классический Zapret2 от bol-van нет.
6. **AWG Test / Podkop VPN Failover** — [TMN88/podkop-vpn-failover-owrt](https://github.com/TMN88/podkop-vpn-failover-owrt), адаптированная копия для `opkg` и `apk`.
7. **Site Checker** — [TMN88/Site_Checker](https://github.com/TMN88/Site_Checker).

Выберите номера через пробел или запятую, `A` для всех или `Q` для выхода. Если введено пустое или некорректное значение, скрипт попросит повторить ввод. Уже обнаруженные компоненты пропускаются. Ошибка установки одного компонента не мешает попыткам установить следующие.

## Совместимость и ограничения

- Целевая область этой версии — OpenWrt 24.10 (`opkg`) и 25.12 (`apk`). Совместимость конкретного стороннего установщика зависит от проекта; скрипт не гарантирует работу каждого компонента на каждом роутере.
- На OpenWrt 24.x/25.x скрипт автоматически устанавливает `luci-i18n-base-ru` в тихом режиме до установки выбранных компонентов. Если пакет уже установлен, установка пропускается; отдельного пункта меню нет.
- **AmneziaWG** использует feed и подписанный ключ из репозитория 2Grey. Скрипт запускает `amneziawg-feed-install.sh` без параметра `-r`; установка русской локализации AmneziaWG этим вызовом отдельно не запрашивается.
- **VPN Failover** рассчитан на OpenWrt 24.10 и 25.12. Для работы нужны Podkop в VPN-режиме и AmneziaWG-интерфейсы с именами `awg*`.
- **Zapret2 Routerich** ограничен target `mediatek/filogic`, архитектурой семейства `aarch64_cortex-a53` и поддерживаемыми версиями OpenWrt. При несовместимости или недоступности пакетов скрипт показывает ошибку и не устанавливает альтернативную реализацию автоматически. Для apk используется `--allow-untrusted`; проверяйте источник и пакеты перед установкой.
- В конце выводится сводка по компонентам, очищаются временные файлы текущего запуска и оставшиеся старые каталоги `/tmp/install-packets-*` (активные запуски пропускаются), затем предлагается перезагрузка роутера.
- Обычный Zapret и Zapret2, а также разные реализации Zapret2, конфликтуют. Не запускайте их параллельно.
- Проверка «уже установлен» основана на именах пакетов и известных файлах. После установки проверяйте статус командами соответствующего проекта.

## Безопасность и тестирование

Перед запуском сделайте резервную копию конфигурации роутера. Скрипт проверяет shell-синтаксис скачанного установщика; это не заменяет аудит кода и проверку источника. Все сторонние установщики выполняются с правами `root`.

CI проверяет shell-синтаксис и наличие ключевых веток, но не заменяет функциональные испытания на физическом роутере.
