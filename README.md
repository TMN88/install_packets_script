# Install Packets Script 2.0

Интерактивный установщик для OpenWrt 24.10.x (`opkg`) и 25.12.x (`apk`). Версия: **2.0.1**. BusyBox ash / POSIX sh.

## Запуск — команда сохранена

```sh
wget -O /tmp/install_packets_script.sh \
  https://raw.githubusercontent.com/TMN88/install_packets_script/main/openwrt-toolkit.sh \
  && sh /tmp/install_packets_script.sh
```

Команда запускает опубликованную версию из `main`; изменения нового PR доступны после его слияния.

Номера можно разделять пробелами и запятыми; повторения игнорируются. Действия выполняются в порядке выбора. Ошибка одного компонента не останавливает остальные. План выводится до установки без общего запроса подтверждения.

**A** выбирает только AmneziaWG, Site Checker 2.0, USB Modules и Watchdog. Podkop/Forkop, Zapret Manager/Routerich, VPN Failover, Tailscale, темы, SFTP и ttyd остаются ручным выбором. Несовместимые пункты пропускаются. Классический Zapret2 автоматически не устанавливается.

Русская локализация LuCI устанавливается автоматически после выбора компонентов, уже установленная пропускается. При Q или завершении ввода установки нет. Границы НАЧАЛО / КОНЕЦ и итоговая таблица показываются по-русски; `NO_COLOR=1` отключает ANSI.

## Совместимость и сохранение настроек

Проверяются точная ветка OpenWrt, соответствие менеджера пакетов и наличие архитектуры. Routerich имеет дополнительный строгий фильтр target/архитектуры. Для остальных внешних компонентов конкретные сборки, архитектуры и зависимости проверяет их штатный установщик / менеджер пакетов. Наличие пункта меню не означает поддержку любого процессора; отказ внешней установки учитывается как ошибка. Поддержка оборудования не подтверждена mock-тестами.

Podkop и Forkop не ставятся поверх друг друга, учитываются существующие конфигурации. Zapret Manager не ставится поверх Zapret2; Routerich не заменяет другие варианты Zapret/Zapret2. Существующие полные установки пропускаются после проверки состояния.

Перед миграцией Site Checker сохраняются старые конфигурации, затем выполняется штатный `Site_Checker_2/main/install.sh`. Остатки 1.x не считаются версией 2.0. Рабочая 2.x с зарегистрированным RPC пропускается. Существующие настройки 2.x сохраняет штатный установщик.

Watchdog устанавливается и без Zapret2, с предупреждением. Его собственная диагностика и штатная политика восстановления сохраняются: интервал по умолчанию 180 секунд, подтверждение отказа, ограничение попыток. Параметры уже существующего Watchdog сохраняются даже если внешний установщик пытается мигрировать режим. Полная, но отключённая установка отмечается «ТРЕБУЕТ НАСТРОЙКИ» без включения службы.

SFTP и ttyd устанавливаются **только по выбору**. Порт SSH, ключи, правила входа и firewall не меняются; Dropbear не отключается, OpenSSH daemon не устанавливается. Для Dropbear при необходимости создаётся отсутствующая ссылка на штатный subsystem. Для OpenSSH проверяется эффективный Subsystem через `sshd -T`; неподтверждённая интеграция требует ручной настройки. Установка пакета не является проверкой подключения из Termius/WinSCP.

Tailscale запускается оригинальными скриптами, без передачи auth key аргументами основного установщика и без журналирования ключей. Userspace и SOCKS5 `0.0.0.0:1055` проверяются по работающему процессу; DNS/netfilter/приём маршрутов — по prefs. Рабочая выбранная сеть пропускается. Перед перенастройкой существующей установки требуется явный выбор. TS Mini блокируется для чужой/неопределённой регистрации; Routerich использует штатное подтверждение переключения и скрытый запрос Device Auth Key. Удалённый SSH по Tailscale IP не обещается.

Темы запускают оригинальное меню. Перед запуском сохраняется конфигурация LuCI, при ошибке она восстанавливается. Другие темы не удаляются, перезагрузки нет. Выбранная активная тема указывается в отчёте. Отмена не считается успешной активацией.

Приватные резервные копии приложений хранятся в `/etc/install-packets-backups/run.*/` (каталоги 700, umask 077). Они не удаляются автоматически. Перед сетевыми установщиками сохраняются network/firewall/dhcp и конфигурации обходчиков; перед Tailscale — конфигурация, init, hotplug и состояние регистрации. Копии могут содержать секреты — храните их как конфигурацию роутера. Восстановление сетевых настроек выполняется вручную после анализа причины ошибки, чтобы не прервать доступ произвольным откатом.

Внешние shell-файлы загружаются только с заданных HTTPS-источников в отдельный временный каталог, проверяются на непустое содержимое, shebang и `sh -n`. Штатные проверки SHA256 Site Checker, Watchdog и установщика тем сохраняются. Внешние URL указывают на текущие штатные установщики: их последующие изменения не являются протестированной частью этой версии. Временный каталог текущего запуска удаляется; чужие/старые каталоги не очищаются.

Скрипт не вызывает `reboot`. После подтверждённой установки AmneziaWG в текущем запуске напоминает о ручной перезагрузке при необходимости.

## Результаты

Статусы: УСПЕШНО, УСТАНОВЛЕН РАНЕЕ, ОШИБКА, НЕ ПОДДЕРЖИВАЕТСЯ, ТРЕБУЕТ НАСТРОЙКИ, ПРОПУЩЕНО. Нулевого кода внешнего установщика недостаточно: проверяется конечное состояние. Ошибки дают ненулевой итоговый код; ручная настройка и пропуски отражаются отдельно.

## Проверки

```sh
sh -n openwrt-toolkit.sh
busybox ash -n openwrt-toolkit.sh
shellcheck --severity=style --shell=sh openwrt-toolkit.sh
python3 -m unittest discover -s tests -v
```

CI повторяет синтаксические проверки, ShellCheck и mock-сценарии под dash и BusyBox ash. Тесты не скачивают и не выполняют внешние установщики: их заменяют управляемые имитации. Проверяются opkg/apk, конфликты, повторный запуск, частичные ошибки, миграция, SFTP, Tailscale, темы, отсутствие GitHub и ложный код успеха.

**Реальное аппаратное тестирование этой версии не проводилось.** Успешные mock-тесты не подтверждают SFTP-сессию, удалённый SSH, восстановление YouTube или работу модулей ядра на конкретном роутере.

## Третий вариант Tailscale: TS AUTO (2.0.1)

В пункте 11 добавлен вариант **3. TS AUTO** — официальный сервер Tailscale, скрытый запрос auth key через терминал при необходимости. Запускается оригинальный [TS_client_install_auto.sh](https://github.com/TMN88/TS_client_install/blob/58fb27565f3d1dcbf2d8fb6ce73ad16afbea29c2/TS_client_install_auto.sh), закреплённый на указанном коммите. Аргументы и ключи основной установщик ему не передаёт. Для скрытого ввода нужен SSH с TTY.

Рабочая официальная регистрация с нужными параметрами пропускается. Перед перенастройкой существующей официальной установки запрашивается подтверждение. Чужой или неизвестный сервер блокируется до запуска AUTO, поскольку сам дочерний скрипт проверяет сервер после изменения службы. Состояние регистрации и конфигурации предварительно копируются; результат проверяется общими проверками Tailscale, включая Running, userspace, SOCKS5 и сервер управления. Режим A Tailscale не выбирает.
