# Install Packets Script for OpenWrt

Интерактивный shell-скрипт для выборочной установки сетевых компонентов на OpenWrt. Предназначен для запуска из SSH под `root`.

## Быстрый запуск

```sh
wget -O /tmp/install_packets_script.sh https://raw.githubusercontent.com/TMN88/install_packets_script/main/openwrt-toolkit.sh && sh /tmp/install_packets_script.sh
```

Скрипт покажет модель роутера, версию OpenWrt и менеджер пакетов, предложит выбрать компоненты и запросит подтверждение до начала установки.

## Доступные компоненты

1. **Podkop** — [itdoginfo/podkop](https://github.com/itdoginfo/podkop).
2. **AmneziaWG** — [Slava-Shchipunov/awg-openwrt](https://github.com/Slava-Shchipunov/awg-openwrt); запускается с параметром, пропускающим создание туннеля.
3. **Zapret Manager** — [StressOzz/Zapret-Manager](https://github.com/StressOzz/Zapret-Manager).
4. **Zapret2 от Routerich** — пакеты и вспомогательные файлы стратегий; ограничения описаны ниже.
5. **AWG Test / Podkop VPN Failover** — [SVTagan/podkop-vpn-failover](https://github.com/SVTagan/podkop-vpn-failover).
6. **Site Checker** — [TMN88/Site_Checker](https://github.com/TMN88/Site_Checker).

В меню можно ввести номера через пробел или запятую, `A` для всех компонентов или `Q` для выхода. При выборе всех компонентов неподдерживаемые установщики будут пропущены, а несовместимость Zapret/Zapret2 проверяется отдельно.

## Совместимость и ограничения

- Общая цель — OpenWrt с `opkg` (например, 24.10) или `apk` (например, 25.12). Совместимость каждого стороннего установщика зависит от самого проекта.
- **AWG Test / Podkop VPN Failover** пропускается на OpenWrt 25.x / системах с `apk`, так как оригинальный установщик требует совместимую систему с `opkg`.
- **Zapret2 Routerich** в этом скрипте ограничен OpenWrt 24.10/`opkg` или 25.12/`apk` и архитектурой пакетов `aarch64_cortex-a53` на target `mediatek/filogic`. Пакеты скачиваются из стороннего источника; на OpenWrt 25.12 может потребоваться установка неподписанных пакетов. Устанавливайте их только если доверяете источнику.
- Обычный Zapret и Zapret2 рассматриваются как несовместимые: скрипт откажется ставить Zapret2, если обнаружит стандартный Zapret.
- Русский перевод ставится только если подходящий пакет опубликован в подключённых feeds или предоставлен самим установщиком.
- Скрипт не автоматизирует подтверждение миграции конфигурации или удаления конфликтующих пакетов в установщике Podkop. Следуйте подсказкам на экране.
- Все выбранные сторонние установщики выполняются с правами root. Перед началом сделайте резервную копию конфигурации роутера.

## Важное замечание

Скрипт — оболочка над установщиками и файлами сторонних проектов, а не официальный пакет этих проектов. Проект не проходил проверку на физическом роутере в рамках подготовки репозитория; проверяйте изменения и исходники перед запуском в рабочей сети.
